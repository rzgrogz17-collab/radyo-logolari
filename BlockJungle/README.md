# Block Jungle

Android block puzzle. The game runs in a WebView. Ads are banner, interstitial and rewarded.

## Switch ads

In `app/src/main/res/values/strings.xml`:

| `use_admob` | Network |
| --- | --- |
| `true` | Google AdMob |
| `false` | Yandex Ads |

Yandex uses SDK 7.15.2. Demo placement ids are already filled in. Replace them, and the AdMob ids, before a store release.
